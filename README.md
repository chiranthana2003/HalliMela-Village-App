# HalliMela - GramHaat 🏺

**HalliMela** (meaning Village Fair in Kannada) is a beautifully designed Android application that brings the authentic experience of a rural Indian market (GramHaat) to your fingertips. This app is designed to promote local artisans and traditional products, making it easier for users to discover and support rural craftsmanship.

## ✨ Features

- **Aesthetic Splash Screen:** A warm welcome to the app with a traditional village-themed loading screen.
- **Vibrant Marketplace:** A 2-column grid layout that mimics a busy mela stall, displaying a wide variety of handmade products.
- **Smart Search:** Easily find specific crafts or items using the real-time search functionality.
- **Product Details:** Click on any item to view its price, history, and usage details in an elegant dialog.
- **Smooth UX:** Optimized with `CoordinatorLayout` and `NestedScrollView` for a seamless scrolling experience across long lists of items.
- **Local Impact:** Focuses on items like Clay Pots, Handwoven Sarees, Organic Jaggery, and more.

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** XML with Material Design 3
- **Navigation/Architecture:** AppCompat & Activity-based architecture
- **Components:**
    - `RecyclerView` with `GridLayoutManager`
    - `CardView` for modern product cards
    - `CoordinatorLayout` & `NestedScrollView` for advanced UI behavior
    - `SearchView` for real-time filtering
- **Image Loading:** Glide (for high-performance image rendering)
